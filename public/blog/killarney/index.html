About Killarney

Job Scheduler (Slurm)

The Killarney cluster, like multiple other clusters, uses Slurm to manage the workload across hundreds of users. In summary, Slurm manages the queue of jobs to be run so all users have access to resources. This means that instead of running your code directly on the node you ssh into (so-called login nodes) you have to first get a compute node allocated to you by Slurm.

There are two types of sessions: interactive sessions and batch sessions. The former is used to run scripts
